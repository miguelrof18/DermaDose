# Importacion inicial

Este repositorio se preparo a partir del paquete `Calculador_Dosis_Piel_Proyecto_v0.5.3.zip`.

Se incluyo:

- codigo fuente del paquete Python;
- ejemplos y plantillas ligeras;
- scripts de reproduccion;
- pruebas automaticas;
- documentacion tecnica, memoria, auditoria, roadmap y validacion;
- assets de demostracion necesarios para ejecutar el modo de malla, con sus notas de licencia.

Se excluyo:

- carpetas `results/` y `research_results/` generadas por ejecuciones previas;
- HTML interactivos generados;
- mapas `NPZ`, imagenes y DICOM sinteticos de salida;
- artefactos temporales de LaTeX y caches.

La motivacion es conservar un historial Git manejable y reproducible. Las salidas pesadas deben regenerarse desde el codigo y, si hace falta preservarlas, guardarse como artefactos externos o releases.
