# Ejemplo 08

El caso de trabajo utiliza un RDSR Azurion y una superficie derivada de un TC. Para reproducirlo dentro del entorno autorizado, coloca el RDSR, la configuración de equipo y, si procede, el STL con su JSON de Slicer en una carpeta local. Sigue los comandos del README principal.

La demostración pública equivalente para comprobar instalación, trazado, acumulación y visor se genera con:

```powershell
python -m skindose_verifier demo --model mesh --out resultados/ejemplo08_sintetico --stage skin_dose
```

La demostración utiliza datos ficticios. Los archivos del procedimiento original se gestionan fuera del repositorio.
