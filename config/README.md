# Configuraciones

Aquí se guardan configuraciones JSON reutilizables. Las configuraciones de referencia actuales son:

- `equipo_xcat_benmakhlouf_investigacion.json`: XCAT50 con factores tabulados Benmakhlouf.
- `equipo_xcat_sintetico_historico.json`: XCAT50 con `bsf` y `f_skin` constantes sintéticos.

Las rutas relativas se resuelven desde la carpeta del propio JSON. Para explicar todos los campos, consulta `documentacion/GUIA_CONFIGURACION_JSON.md`.
